# Notebooks del tema 06: CUDA C++

El módulo CUDA tiene seis sesiones y un máximo de tres notebooks:

1. `01_modelo_cuda.ipynb`: toolchain CUDA 13, SIMT, grid/bloque/hilo, primer kernel y manejo de errores.
2. `02_memoria_tiling.ipynb`: transferencias, coalescencia, memoria compartida, bancos y multiplicación de matrices validada.
3. `03_reducciones_perfiles.ipynb`: divergencia, atomics, primitivas de warp, streams, ocupación, Nsight y Roofline.

Cada notebook deberá ejecutar fuentes de `curso/ejemplos/06_cuda/`, comprobar una referencia CPU y construir sus gráficas desde datos exportados.
