# Ejercicios

Los ejercicios se organizan por tema y número, por ejemplo `03_openmp/02_histograma/`. Cada ejercicio incluye:

- enunciado y resultados de aprendizaje;
- esqueleto de código;
- entrada pequeña y salida esperada;
- pruebas públicas;
- criterios de rendimiento solo después de pasar corrección;
- rúbrica breve.

Las soluciones de referencia están en `soluciones/` y pueden excluirse de la rama distribuida a estudiantes.
