# Notebooks de tópicos avanzados

Cada unidad tendrá entre uno y tres notebooks en `01_rocm_hip/`, `02_sycl/`, `03_kokkos/` o `04_raja/`.

Los notebooks siguen la [guía para temas avanzados](../PLANTILLA_TEMA.md) y registran el perfil de compilación, backend, dispositivo, controlador y versiones utilizados en la ejecución. Las imágenes conceptuales conservan el estilo de boceto técnico a lápiz; las gráficas se construyen con datos trazables y se concentran en una pregunta de análisis.

Las implementaciones completas permanecen en `../ejemplos/`. Los notebooks las construyen y ejecutan sin duplicarlas en las celdas.
