# Notebooks de tópicos avanzados

Se crearán entre uno y tres notebooks por cápsula en `01_rocm_hip/`, `02_sycl/`, `03_kokkos/` y `04_raja/`.

Cada notebook seguirá [`PLANTILLA_TEMA.md`](../PLANTILLA_TEMA.md), declarará perfil de compilación, backend, dispositivo, controlador y versiones efectivamente utilizados. Las imágenes conceptuales seguirán el estilo de boceto técnico a lápiz; las gráficas tendrán una sola pregunta, pocas series y datos trazables.

Los notebooks no contendrán implementaciones extensas copiadas en celdas: construirán y ejecutarán los fuentes de `../ejemplos/`.
