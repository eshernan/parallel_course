# Ejemplos de tópicos avanzados

Los ejemplos se organizan en `01_rocm_hip/`, `02_sycl/`, `03_kokkos/` y `04_raja/`.

Cada ejemplo incluye referencia serial, pruebas de corrección, manejo de errores, construcción con CMake, instrucciones de ejecución, manifiesto de compilador, bibliotecas, backend y hardware, además de exportación de métricas. La documentación enumera únicamente los backends que hayan sido probados. Una compilación para CPU, por sí sola, no establece soporte para GPU.
