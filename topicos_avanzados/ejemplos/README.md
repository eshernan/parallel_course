# Ejemplos de tópicos avanzados

La estructura prevista es `01_rocm_hip/`, `02_sycl/`, `03_kokkos/` y `04_raja/`.

Todo ejemplo tendrá referencia serial, pruebas de corrección, manejo de errores, CMake, instrucciones de ejecución, manifiesto de compilador/librerías/backend/hardware y exportación de métricas. Una variante se anunciará como portable solo después de probar cada backend declarado; compilar sobre CPU no demuestra soporte de GPU.
