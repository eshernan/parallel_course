# Ejercicios de tópicos avanzados

Cada ejercicio se almacenará en `<topico>/<id>/` e incluirá enunciado, prerrequisitos conceptuales, esqueleto, datos pequeños, salida esperada, pruebas públicas y rúbrica.

También debe completar la ficha de [`ENTORNOS_CLUSTER.md`](../ENTORNOS_CLUSTER.md): compilador, librerías, backend, GPU, módulos, partición, recursos y comandos de construcción/ejecución. Las comparaciones entre HIP, SYCL, Kokkos y RAJA usarán el mismo problema, precisión, datos y criterio de validación.
