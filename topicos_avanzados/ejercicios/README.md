# Ejercicios de tópicos avanzados

Cada ejercicio se almacena en `<topico>/<id>/` e incluye enunciado, prerrequisitos conceptuales, código inicial, datos pequeños, salida esperada, pruebas públicas y rúbrica.

La entrega incorpora la ficha de [`ENTORNOS_CLUSTER.md`](../ENTORNOS_CLUSTER.md), con compilador, bibliotecas, backend, GPU, módulos, partición, recursos y comandos de construcción y ejecución. Las comparaciones entre HIP, SYCL, Kokkos y RAJA conservan el problema, la precisión, los datos y el criterio de validación.
